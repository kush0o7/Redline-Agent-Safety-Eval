# Code of conduct

Redline adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and assume good faith. People join from many countries, languages and levels of experience.
- Critique ideas and code, not people.
- No harassment, insults, sexual content, or personal attacks, in any project space (issues, pull requests, discussions, chat).
- No publishing other people's private information.

## Safety-research content

Redline is about adversarial testing, so harmful prompts come up. Some extra rules:

- Discuss attacks to improve defences. Don't post working instructions for serious real-world harm (weapons, malware, abuse material) beyond what a test case needs. Test cases describe a request; they never need a full harmful answer.
- Never post real customer data, personal data, or secrets in an issue, a test case or a report.
- Report a vulnerability in Redline privately (see [SECURITY.md](SECURITY.md)), not in a public issue.

## Reporting

If someone breaks these rules, contact the maintainers privately: use the repository's **Security → Report a vulnerability** form and say it's a conduct report, or GitHub's **Report content** option on the comment. Reports are kept confidential. Maintainers may edit or remove content, and warn, suspend or ban a contributor, following the Covenant's enforcement guidelines.
